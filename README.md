# Book Library API

Это RESTful API для управления каталогом книг и категорий, разработанное на **FastAPI** с использованием **PostgreSQL** в качестве базы данных.

## 🚀 Функционал
* Управление категориями книг (CRUD).
* Управление книгами (CRUD) с автоматической валидацией категорий.
* Фильтрация книг по `category_id`.
* Интерактивная документация Swagger UI.

## 🛠 Технологический стек
* **Python 3.14**
* **FastAPI** — веб-фреймворк.
* **SQLAlchemy** — ORM для работы с БД.
* **PostgreSQL** — база данных.
* **Uvicorn** — ASGI-сервер.
